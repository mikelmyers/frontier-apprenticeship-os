# Foundation Bridge Daily Lessons

This folder contains the lower-level prerequisite lessons that come before the harder frontier/aerospace track.

These lessons are intentionally slower and deeper than the first advanced lessons. They rebuild Python fluency while teaching the math and physics notation used later in the apprenticeship.

## Working Rule

For now, complete these before returning to the harder lessons.

Do not treat this as going backward. This is the bridge layer that makes the harder material usable.

## Daily Completion Checklist

For each lesson:

- Read the concept explanation.
- Decode every symbol.
- Type the Python manually.
- Run the file.
- Modify the code at least once.
- Answer the quiz in `quizzes/000-foundation-bridge/`.
- Save any notes in `memos/000-foundation-bridge/`.

## AI Usage Rule

The first code attempt must be typed manually.

AI can be used after the first attempt as a reviewer, debugger, or tutor, but not as the first author.

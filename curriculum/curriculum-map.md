# Curriculum Map

## Program Target

Become frontier-adjacent in AI-assisted autonomous space infrastructure engineering within one year.

Capstone: **Autonomous Depot Network Simulator + Technical White Paper**.

## Module Sequence

### Module 01 — Mathematical Foundations for Simulation
Vectors, matrices, coordinate frames, derivatives, numerical integration, dimensional analysis, uncertainty basics.

Primary artifact: reusable Python math primitives for simulation.

### Module 02 — Physics and Mechanics
Newtonian mechanics, energy, momentum, rotational dynamics, constraints, stability, scaling laws.

Primary artifact: motion and force simulation suite.

### Module 03 — Orbital Mechanics
Two-body motion, Keplerian elements, Hohmann transfers, patched conics, Lagrange points, CR3BP foundations.

Primary artifact: depot node and transfer-path simulation.

### Module 04 — Control Systems
Feedback, PID, state-space models, stability, guidance/navigation/control, Kalman filtering.

Primary artifact: station-keeping or docking-control simulator.

### Module 05 — Robotics and Autonomy
Sensors, perception, mapping, path planning, autonomy loops, inspection robotics, fault handling.

Primary artifact: autonomous inspection/drone task planner.

### Module 06 — AI/ML for Engineering Systems
Regression, classification, time-series modeling, anomaly detection, forecasting, reinforcement learning foundations.

Primary artifact: telemetry anomaly detection model.

### Module 07 — Systems Engineering
Requirements, interfaces, verification, validation, FMEA, trade studies, operational constraints.

Primary artifact: Trailblazer subsystem requirements and V&V matrix.

### Module 08 — Spacecraft Architecture
Power, thermal, communications, structures, propulsion, docking, avionics, redundancy, maintainability.

Primary artifact: Pin Depot architecture baseline.

### Module 09 — Simulation and Digital Twins
Monte Carlo methods, uncertainty propagation, digital twins, scenario testing, model validation.

Primary artifact: depot digital twin v0.1.

### Module 10 — Agentic Engineering Workflows
Research agents, code agents, test agents, simulation agents, critique agents, report agents.

Primary artifact: AI-assisted engineering workflow for capstone development.

### Module 11 — Research and Technical Writing
Literature review, technical memos, white papers, design reviews, claims discipline, evidence framing.

Primary artifact: Trailblazer technical white paper draft.

### Module 12 — Capstone Integration
Integrate simulation, autonomy, systems engineering, and technical writing.

Primary artifact: autonomous depot network simulator and final technical white paper.

## Lesson Completion Rule

A lesson is complete only when:

1. the exercise has been attempted,
2. the quiz has been answered,
3. at least one artifact has been created or updated,
4. the result has been reported back to the lesson agent.

## Advancement Rule

Advance only when the weekly review confirms adequate performance across:

- conceptual understanding,
- mathematical fluency,
- code implementation,
- engineering judgment,
- artifact quality.

If a weak area scores below 3/5, insert repair lessons before advancing.

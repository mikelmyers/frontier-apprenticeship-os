# Module 000 — Foundation Bridge Track

## Purpose

This module comes before the existing harder aerospace/frontier lessons.

The current program is not being discarded. It is being preceded by a lower-friction foundation layer so the apprentice can rebuild:

- Python fluency
- technical notation literacy
- vector intuition
- mechanics intuition
- simulation habits
- engineering artifact discipline

The goal is not remedial algebra. The goal is to make the symbols, code patterns, and physics ideas readable enough that the advanced track becomes productive instead of frustrating.

## Agent Routing Rule

Until this module is completed, lesson-generation agents should prioritize Module 000 content.

Advanced aerospace lessons should be paused as daily assignments unless they are converted into prerequisite decoder lessons.

Acceptable advanced-agent behavior during this module:

1. Generate foundation lessons.
2. Decode previously assigned advanced lessons into simpler prerequisites.
3. Create review questions based on Module 000.
4. Inspect completed artifacts and assign repair lessons.

Unacceptable behavior during this module:

1. Assign CR3BP, manifold, orbital optimization, or high-density notation lessons without a prerequisite decoder.
2. Assume comfort with vector notation, derivatives, orbital mechanics, or Python implementation.
3. Skip directly to advanced problem sets.

## Lesson Format

Each lesson must include:

1. Plain-English concept
2. Why it matters for Trailblazer or autonomous space infrastructure
3. Notation decoder
4. Small numeric example
5. Python implementation
6. Debugging or modification exercise
7. Short quiz
8. Required repo artifact

## Depth Requirement

Problems should not appear before the concept has been explained. Each concept lesson should spend enough time on:

- physical intuition
- vocabulary
- notation
- code mapping
- common misunderstandings

Only then should the apprentice solve exercises.

## Completion Standard

Module 000 is complete when the apprentice can manually write and explain a small Python program that calculates:

- relative position
- distance / vector magnitude
- relative velocity
- range safety status
- a simple multi-step vehicle approach simulation

The code does not need to be advanced. It must be understood, runnable, and explainable.

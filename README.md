# Frontier Apprenticeship OS

A one-year AI-managed apprenticeship for becoming frontier-adjacent in **AI-assisted autonomous space infrastructure engineering**.

This repository is the permanent artifact home for daily lessons, simulations, technical memos, quizzes, and the year-long capstone.

## One-Year Target

Develop working competence in the technical stack needed to reason about, simulate, document, and prototype autonomous space logistics infrastructure.

Primary capstone:

> **Autonomous Depot Network Simulator + Technical White Paper**

The capstone should eventually model depot nodes, transfer paths, vehicle state, mission constraints, failure cases, telemetry, autonomy decisions, and engineering tradeoffs.

## Operating Principle

Every lesson must produce evidence.

A lesson is not complete until at least one artifact exists in this repository.

## Repository Structure

```text
curriculum/        Master curriculum map and module plans
daily-lessons/     Daily lesson packets
notebooks/         Jupyter notebooks and exploratory analysis
simulations/       Python simulations and reusable models
memos/             Technical memos and written analysis
quizzes/           Quiz answers and mastery reviews
artifacts/         Diagrams, charts, results, screenshots, datasets
capstone/          Autonomous depot network simulator and final white paper
templates/         Reusable lesson, memo, and review templates
```

## Daily Workflow

1. Receive the daily lesson from the ChatGPT Frontier Apprenticeship OS agent.
2. Complete the assigned exercise.
3. Create or update the specified repo artifact.
4. Answer the quiz.
5. Report completion back to the agent.
6. Let the next lesson adapt based on the result.

## Weekly Workflow

Each Sunday, run a review across five dimensions:

- Conceptual understanding
- Mathematical fluency
- Code implementation
- Engineering judgment
- Artifact quality

Weak areas become repair lessons before advancing.

## Monthly Workflow

On the first of each month, run a curriculum steering session.

The steering session adjusts the next module based on:

- completed artifacts
- current technical weaknesses
- Trailblazer requirements
- capstone progress
- changes in robotics/autonomy priorities

## Standard

This is not a passive course. It is a technical apprenticeship.

The lessons should be dense, artifact-driven, and increasingly rigorous. Fundamentals are allowed only when they directly support engineering, simulation, autonomy, or systems reasoning.
